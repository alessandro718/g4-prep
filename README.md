# G4 15 天备考练习

一个纯前端的备考练习站点：15 天 × 每天 10 题，自动判分、错题本、学习报告、日历提醒。
无需安装、无需登录、无需服务器，浏览器打开即用。

## 功能

| 页面 | 内容 |
| --- | --- |
| `index.html` | 今日任务、打卡概览、提醒设置 |
| `plan.html` | 15 天路线图与完成进度 |
| `quiz.html` | 每日 10 题（英语 5 / 数学 3 / 语文 2），点选即判分并显示中文解析 |
| `wrong.html` | 错题本，支持重做当天 |
| `report.html` | 学习报告：15 天正确率柱状图、三科分项、薄弱点、可转发给家长 |
| `info.html` | 考试日期与提醒时间设置、导出 .ics 日历提醒、面试题库 |

题库共 150 道，全部按公开考情自编，非任何学校真题。

## 本地运行

站点是纯静态的，任何静态服务器都可以：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 用 `file://` 打开也可以，但浏览器对本地文件的存储限制不同，建议用上面的方式。

## 部署到 GitHub Pages

1. 新建一个 **public** 仓库（免费账号的 Pages 只支持公开仓库）
2. 把本目录全部文件上传到默认分支根目录
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)` → Save
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

`.nojekyll` 文件已经存在，用于跳过 Jekyll 处理。

## 数据说明

所有进度保存在浏览器 `localStorage`，不上传任何服务器，换设备或清缓存后进度不共享。
